This folder is where you place your release code

# Naming Conventions

Files should be named in this format: YYYY-MM-DD.zip, to match with your release in APEX

# APEX Options

When exporting out of APEX, your screen should look like this:

- Readable Format: Enabled
- Build Status Override: Run and Build Application
- Supporting Object Definitions: Yes
- Split into Multiple Files: Enabled
- Public Reports: Enabled
- Private Reports: Disabled
- Report Subscriptions: Disabled
- Developer Comments: Enabled
- Translations: Enabled
- Debugging: Disabled
- Original IDs: Disabled
- Owner Override: Blank
- Audit Informaiton: Names and Dates
- As of: Blank
